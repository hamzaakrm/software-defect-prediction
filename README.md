# Software Defect Prediction

## MSc Dissertation Project

**Title:** Evaluating Classical Machine Learning Models for Software Defect Prediction: A Comparative Study and a Developer-Facing Prediction Tool

## Aim

To compare classical machine learning models for software defect prediction and develop a simple tool to help developers identify potentially defective software modules.

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- k-Nearest Neighbours (k-NN)
- Naive Bayes
